# Native Splash Screen — Design Spec

Date: 2026-08-20
Status: Approved

## 1. Purpose

Add a polished native launch screen so the app doesn't show a blank/white flash before Flutter's first frame paints. Brand it to match the app icon just shipped (Cobalt Mail: `#0A5BD6` blue, white envelope mark).

## 2. Goals / Non-goals

**Goals**
- Native launch screen (iOS storyboard, Android — including the Android 12+ splash API, web) shown instantly by the OS, no white/blank flash.
- Visually consistent with the app icon: solid `#0A5BD6` background, centered white envelope glyph, no wordmark/text.
- Identical appearance in light and dark system mode (explicit choice — not deferring to OS default, which would otherwise render dark mode as black).

**Non-goals**
- No animation.
- No separate light/dark artwork — one look regardless of theme.
- No in-Flutter (Dart-drawn) splash widget — native only, since that's the only way to avoid the pre-first-frame flash.

## 3. Approach

Use the `flutter_native_splash` package (dev dependency), configured via a `flutter_native_splash:` block in `pubspec.yaml`, generated with `dart run flutter_native_splash:create`. Same pattern already used for `flutter_launcher_icons`.

## 4. Assets

The existing `assets/icon/app_icon.png` can't be reused directly — it has an opaque blue square baked in, which doesn't composite correctly on Android 12's circular safe-zone icon (that API renders the icon on its own background, and expects transparency around the glyph).

New assets:
- `assets/icon/splash_logo.png` — the envelope mark only, transparent background, used for iOS/Android (pre-12)/web.
- `assets/icon/splash_logo_android12.png` — same glyph, more inset, sized to fit Android 12's smaller circular safe zone (icon content confined to the inner ~2/3 of the canvas per platform guidance).

Both generated by script (Pillow), matching the icon's geometry (rounded envelope body + darker-blue flap triangle) minus the background fill.

## 5. Configuration

```yaml
flutter_native_splash:
  color: "0A5BD6"
  color_dark: "0A5BD6"        # explicit — otherwise dark mode defaults to black
  image: assets/icon/splash_logo.png
  image_dark: assets/icon/splash_logo.png
  android_12:
    image: assets/icon/splash_logo_android12.png
    image_dark: assets/icon/splash_logo_android12.png
    color: "0A5BD6"
    color_dark: "0A5BD6"
  android: true
  ios: true
  web: true
```

## 6. Verification

- Run the generator, rebuild on the iOS simulator, confirm the launch screen shows the blue background + envelope mark with no white flash before the app UI takes over.
- Spot-check Android 12 config values against current `flutter_native_splash` docs at implementation time (the safe-zone sizing convention has shifted across package versions).
