# Native Splash Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native launch screen (iOS/Android/web) so the app shows the Cobalt Mail brand (blue background, white envelope glyph) instantly on cold start, with no white/blank flash.

**Architecture:** Generate two new transparent-background PNG assets (the envelope glyph, plus an Android-12-safe-zone variant), configure the `flutter_native_splash` package in `pubspec.yaml`, and run its generator to produce native launch-screen files (iOS storyboard, Android XML/drawables, web HTML/manifest) — no Dart code is added; the splash is entirely native and shown before the Flutter engine attaches.

**Tech Stack:** Flutter/Dart, Python 3 + Pillow (asset generation, same tool used for the app icon), `flutter_native_splash` package.

## Global Constraints

- Background color, both light and dark mode: `#0A5BD6` (spec §5 — explicit `color` and `color_dark`, not left to OS default).
- No animation, no wordmark/text, no separate light/dark artwork (spec §2 non-goals).
- Glyph geometry must match the existing app icon's envelope mark (rounded body, corners `(False, False, True, True)`, radius 56, darker-blue flap triangle) — spec §4.
- Splash image must have a transparent background (not the opaque square baked into `assets/icon/app_icon.png`) — spec §4.
- All platforms enabled: iOS, Android (incl. Android 12+ splash API), web — spec §5.

### Task 1: Generate the transparent splash glyph assets

**Files:**

- Create (generated by the script): `assets/icon/splash_logo.png`
- Create (generated by the script): `assets/icon/splash_logo_android12.png`

**Interfaces:**
- Produces: `assets/icon/splash_logo.png` — 1024×1024 RGBA PNG, transparent background, envelope glyph filling roughly the same footprint as the icon's glyph (620×420 body, centered with the existing +40px vertical offset).
- Produces: `assets/icon/splash_logo_android12.png` — 1024×1024 RGBA PNG, transparent background, same glyph scaled down and centered so all opaque pixels stay within the inner 682×682 px (2/3 of the 1024 canvas, per Android 12 splash-icon safe-zone guidance) — this is what Task 2's `android_12:` config block consumes.

- [ ] **Step 1: Write the asset-generation script**

Create `tool/gen_splash_assets.py`:

```python
"""Generate transparent-background splash glyph assets for flutter_native_splash.

Two outputs:
  - splash_logo.png: full-size glyph (matches the app icon's envelope
    geometry) for iOS / Android pre-12 / web, where flutter_native_splash
    itself centers the image on the solid background color.
  - splash_logo_android12.png: the same glyph scaled down so all opaque
    pixels stay within Android 12's circular safe zone (per current
    platform guidance, icon content must stay within the inner ~2/3 of
    the canvas — https://developer.android.com/develop/ui/views/launch/splash-screen).

Both are fully transparent outside the glyph — no background fill, unlike
assets/icon/app_icon.png (which has an opaque square baked in for the
app icon itself and is NOT reused here).
"""
from PIL import Image, ImageDraw

SIZE = 1024
WHITE = (255, 255, 255, 255)
FLAP = (6, 64, 158, 255)  # matches gen_icon.py's FLAP color, alpha added


def draw_envelope(canvas_size, scale=1.0):
    """Draws the envelope glyph on a transparent canvas of canvas_size,
    scaled by `scale` around the canvas center. scale=1.0 reproduces the
    exact geometry used for the app icon's glyph."""
    img = Image.new("RGBA", (canvas_size, canvas_size), (0, 0, 0, 0))
    draw = ImageDraw.Draw(img)

    body_w, body_h = int(620 * scale), int(420 * scale)
    left = (canvas_size - body_w) // 2
    top = (canvas_size - body_h) // 2 + int(40 * scale)
    right = left + body_w
    bottom = top + body_h
    radius = int(56 * scale)

    draw.rounded_rectangle(
        [left, top, right, bottom], radius=radius, fill=WHITE,
        corners=(False, False, True, True),
    )
    draw.rectangle([left, top, right, top + radius], fill=WHITE)

    apex_y = top + int(190 * scale)
    draw.polygon(
        [(left, top), (right, top), ((left + right) // 2, apex_y)],
        fill=FLAP,
    )
    return img


# Full-size glyph — matches the icon exactly.
glyph = draw_envelope(SIZE, scale=1.0)
glyph.save("assets/icon/splash_logo.png", "PNG")

# Android 12 safe-zone variant — same shape, scaled to 0.62x so the glyph's
# bounding box (620x420 at scale=1.0) shrinks to fit within the inner
# 682x682 safe zone with margin to spare.
glyph_a12 = draw_envelope(SIZE, scale=0.62)
glyph_a12.save("assets/icon/splash_logo_android12.png", "PNG")

print("saved splash_logo.png and splash_logo_android12.png")
```

### Task 2: Configure and generate the native splash screens

**Files:**
- Modify: `pubspec.yaml` (add `flutter_native_splash` dev dependency at line 60, after the existing `flutter_launcher_icons: ^0.14.4` line; add a `flutter_native_splash:` top-level config block after the existing `flutter_launcher_icons:` block, which currently ends at line 80)

**Interfaces:**
- Consumes: `assets/icon/splash_logo.png` and `assets/icon/splash_logo_android12.png` from Task 1.
- Produces: native launch-screen files under `ios/Runner/Assets.xcassets/LaunchImage.imageset/`, `ios/Runner/Base.lproj/LaunchScreen.storyboard`, `android/app/src/main/res/drawable*/`, `android/app/src/main/res/values*/styles.xml`, `web/splash/` and `web/index.html` — consumed by the OS at app launch, not referenced anywhere in Dart code.

- [ ] **Step 1: Add the dependency to `pubspec.yaml`**

In `pubspec.yaml`, change:
```yaml
  flutter_launcher_icons: ^0.14.4
```
to:
```yaml
  flutter_launcher_icons: ^0.14.4
  flutter_native_splash: ^2.4.6
```

- [ ] **Step 2: Add the configuration block**

In `pubspec.yaml`, immediately after the existing `flutter_launcher_icons:` block (which ends right before the `# For information on the generic Dart part of this file...` comment), add:

```yaml
flutter_native_splash:
  color: "0A5BD6"
  color_dark: "0A5BD6"
  image: assets/icon/splash_logo.png
  image_dark: assets/icon/splash_logo.png
  android_12:
    image: assets/icon/splash_logo_android12.png
    image_dark: assets/icon/splash_logo_android12.png
    color: "0A5BD6"
    color_dark: "0A5BD6"
  android: true
  ios: true
  web: true
```

- [ ] **Step 3: Fetch the new dependency**

Run: `cd ~/imap_mail && flutter pub get`

Expected: completes without error; `pubspec.lock` is updated to include `flutter_native_splash`.

- [ ] **Step 4: Run the generator**

Run: `cd ~/imap_mail && dart run flutter_native_splash:create`

Expected output ends with something like:
```
[√] Splash screen created successfully.
```
